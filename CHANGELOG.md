# Changelog

Fadeno records user-visible release changes here once installable packages
exist. Unreleased repository-foundation work does not create package versions
or tags.

Release sections are generated from reviewed version intent and use these
classifications where applicable: Added, Changed, Fixed, Security,
Documentation, and Internal. Each entry explains the user outcome, names
affected public packages, and links migration guidance for compatibility
changes. Changelogs are not commit-message dumps.
