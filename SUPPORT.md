# Support policy

Fadeno's first public alpha is experimental and is not supported for production
use.

Supported environments, browsers, runtimes, adapters, and compatibility ranges
will be documented only after they pass conformance tests. No environment is
supported merely because it is mentioned in a roadmap or builds locally.

The first alpha is mechanically qualified through current packed
application workflows. Independent newcomer usability, assistive-technology
usability, and any editor product have not been qualified. The private analyzer
is implementation machinery, not a supported protocol or public schema.
