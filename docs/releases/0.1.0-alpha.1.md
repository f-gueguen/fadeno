# Fadeno 0.1.0-alpha.1

This is Fadeno's first registry-installable, experimental alpha. It contains
the same qualified framework behavior as the immutable `0.1.0-alpha.0` source
release. That earlier release stopped before registry upload because hosted
repository visibility evidence was incomplete; its tag remains unchanged.

Install the exact prerelease explicitly:

```sh
pnpm add @fadeno/framework@0.1.0-alpha.1
```

The release includes the routed TypeScript/JSX application workflow, server
rendering and streaming, request-owned resources, native actions and protected
sessions, project creation, framework checks, application tests, transactional
build and development commands, and immutable loopback deployment artifacts.
The canonical application permanently exercises success, deliberate failure,
correction, flow inspection, rollback, recovery, and stale-output removal.

Important limitations:

- This alpha is not production-supported.
- Independent newcomer usability has not been qualified.
- Assistive-technology usability has not been independently qualified.
- There is no supported editor product or public analyzer schema.
- Actions and protected sessions initially have one process owner.
- Browser enhancement remains later work; islands remain later still.

The package is published under the `alpha` distribution tag with generated
provenance. Its source tag, package version, changelog, SPDX SBOM, release
notes, and documentation artifact must identify the same release. Published
versions and source tags are never replaced; a defect is corrected by a newer
prerelease.

See the [first-alpha adoption guide](../migrations/first-alpha-candidate.md),
[support policy](../../SUPPORT.md), and [package changelog](../../packages/framework/CHANGELOG.md).
