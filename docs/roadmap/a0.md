# A0 detailed plan — public alpha

A0 turns the qualified private V1 vertical slice into a public pre-1.0 product
that a new user can install, create, test, diagnose, build, and deploy from
reviewed artifacts. It does not add browser enhancement or islands.

## Entry conditions

- V1 exited through merge commit `d2acf0a` and `pnpm check:v1-exit` derives all
  15 V1-gated features, their executable gates, tracked evidence, bounded
  audits, and residual risks.
- The canonical application succeeds from one current packed private package,
  including check, failure, correction, recovery, build, development, and
  production start.
- The framework package completed V1 as `0.0.0-private`. A0-03 now owns its
  checked transition to the unpublished `0.0.0` public metadata seed; no A0
  slice may publish or claim production support before A0-10.
- The unscoped registry identity is unavailable. ADR 0037 selects the owned,
  unpublished `@fadeno/framework` identity without making it publishable.

## Delivery checkpoints

- **Alpha contract checkpoint — A0-03:** package identity, entrypoints, version
  intent, changelog/changeset rules, provenance, and rollback are accepted and
  mechanically enforced before the package becomes publishable.
- **Independent workflow checkpoint — A0-07:** users working only from public
  artifacts can create, test, diagnose, build, and deploy the canonical slice,
  including seeded failures and stale-state recovery.
- **Tooling checkpoint — A0-08:** external-user evidence either demonstrates a
  concrete analyzer/editor consumer and resolves DG-A0-02 or retains the
  private analyzer and defers a product. Evidence, not preference, selects it.
- **Public alpha exit — A0-10:** one immutable locally qualified commit produces
  the exact public package and documentation artifacts, publishes through the
  accepted provenance boundary, and passes clean public installation.

## Boundaries retained throughout A0

- Stock TypeScript continues to own ordinary TypeScript/JSX language service
  behavior. Fadeno owns only framework semantics.
- The private analyzer does not become a public schema or editor product unless
  A0-07 demonstrates a consumer and DG-A0-02 is resolved by an ADR.
- One logical package remains the default. A second package needs a distinct
  demonstrated consumer and an accepted package-boundary change.
- GitHub does not become a CI gate. The exact commit passes `pnpm ci:local`;
  publication automation, if accepted, may only publish that locally qualified
  immutable source through the separately reviewed provenance boundary.
- Browser enhancement remains V2 and islands remain V3. A0 examples use the
  V1 JavaScript-disabled contract as their essential path.
