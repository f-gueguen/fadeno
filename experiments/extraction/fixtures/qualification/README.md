# Qualification roots

This private K0-06 companion source supplies real server-zone roots and nested
selected closures while importing the K0-05 locked behavior sources as the one
authority for each interaction. `seedInteraction` is an experiment marker, not
a proposed public API.

The candidate must select only the marked closure and the symbols reachable
from it. Unrelated imports in the same root file are deliberate value-flow
canaries. The local-counter root includes the positive plain-data capture.
