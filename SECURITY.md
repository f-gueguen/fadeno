# Security policy

Fadeno has no published package or production-ready release.

Security requirements are tracked in
[docs/security/requirements.md](docs/security/requirements.md). Security
boundaries must be implemented and negatively tested in the same vertical
slice that introduces them; they are not postponed to a final hardening pass.

Once the repository is hosted, private vulnerability reporting must be enabled
before the first public package is published. Until then, do not disclose
suspected vulnerabilities or sensitive reproduction data in a public issue.
